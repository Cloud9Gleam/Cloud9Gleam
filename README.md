# Hatch Worker

Independent security research for ERC-4626 vaults.

- **Live site:** https://check.n1netw3n.live/
- **Free checker:** https://check.n1netw3n.live/checker/ — six exact-integer checks (rounding directions, donation / first-depositor inflation, minimum viable deposit, preview consistency, fee conservation, share-price sanity). No install, no chain access, no spend.
- **Vault micro-audit:** https://check.n1netw3n.live/audit/ — fixed scope (up to 15 files), 50 USDC, 72-hour report.
- **Open source:** [erc4626-checker](https://github.com/Cloud9Gleam/erc4626-checker) — the same checks as runnable Python, stdlib-only, exact integer arithmetic.
- **Research:** https://check.n1netw3n.live/research/ — vault writeups and audit notes.
